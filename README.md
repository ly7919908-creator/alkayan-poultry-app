# تطبيق الكيان فيات للدواجن والأعلاف 🐣🌾
> تطبيق موبايل متكامل لبورصة أسعار الدواجن والأعلاف، الفيديوهات والإرشادات البيطرية، والتواصل الفوري السريع.

---

## 📱 مميزات التطبيق:
1. **واجهة مستخدم عصرية وهادئة:**
   - مبنية بدرجات الأخضر الفاتح والناعم والأبيض النقي المناسبة لنشاط الدواجن والبيطرة.
   - دعم كامل للغة العربية واتجاه اليمين لليسار (RTL).
2. **الصفحة الرئيسية وشاشة الأسعار:**
   - عرض لحظي لأسعار كتاكيت التسمين (أبيض، ساسو، بلدي، روزي) وأسعار الأعلاف (بادي، نامي، ناهي).
   - مؤشرات بيانية لحركة الأسعار (صعود 📈، هبوط 📉، استقرار ➖).
   - إمكانية تعديل الأسعار فورياً بسهولة عبر زر القلم المباشر في البطاقات، مع الحفظ في ذاكرة الجهاز.
   - إمكانية إضافة أصناف جديدة وحساب الفروقات التلقائي.
3. **قسم الفيديوهات والإرشادات:**
   - استعراض نشرات الأسعار المصورة اليومية.
   - إرشادات بيطرية لحضانات الكتاكيت في الأسبوع الأول، برامج التحصين والوقاية، وبرامج التغذية والعلف.
   - فلترة وتصنيف الفيديوهات حسب النوع.
4. **شريط التواصل السريع المباشر:**
   - زر التراسل المباشر عبر واتساب مع رسالة استفسار وحجز معدة مسبقاً.
   - زر الاتصال الهاتفي الفوري بإدارة مبيعات الكيان فيات.

## 📂 هيكلية المشروع (Project Architecture):
```
alkayan_poultry_app/
├── lib/
│   ├── main.dart                      # نقطة البداية وإعدادات اللغة العربية والثيم
│   ├── constants/
│   │   ├── app_colors.dart            # لوحة الألوان الهادئة (أخضر فاتح، أبيض، نعناعي)
│   │   └── app_theme.dart             # خط Cairo وتنسيق الواجهة الموحد
│   ├── models/
│   │   ├── poultry_price.dart         # نموذج بيانات أصناف الكتاكيت والأعلاف
│   │   └── video_guide.dart           # نموذج بيانات الفيديوهات والاستشارات
│   ├── services/
│   │   └── price_storage_service.dart # خدمة إدارة الأسعار والتخزين المحلي وأرقام التواصل
│   ├── screens/
│   │   ├── main_layout_screen.dart    # الشاشة الحاضنة وشريط التنقل السفلي
│   │   ├── home_prices_screen.dart    # شاشة الأسعار الرئيسية والفلترة والبحث
│   │   └── videos_screen.dart         # شاشة مكتبة الفيديوهات والاستشارات البيطرية
│   └── widgets/
│       ├── price_card.dart            # بطاقة عرض السعر مع مؤشر التغير وزر التعديل
│       ├── video_card.dart            # بطاقة الفيديو الإرشادي ومعاينة التشغيل
│       ├── quick_contact_bar.dart     # شريط أزرار الواتساب والاتصال الهاتفي المباشر
│       └── edit_price_dialog.dart     # نافذة التعديل السريع للأسعار
├── pubspec.yaml                       # الاعتماديات (Material, URL Launcher, Fonts..)
└── preview/
    └── index.html                     # نسخة تجريبية تفاعلية تعمل مباشرة في المتصفح
```

## 🚀 طريقة التشغيل عبر Flutter:
1. تثبيت متطلبات فلاتر:
   ```bash
   flutter pub get
   ```
2. تشغيل التطبيق على الهاتف أو المحاكي أو متصفح الويب:
   ```bash
   flutter run
   ```
3. لتغيير أرقام الهواتف أو الواتساب، افتح الملف:
   `lib/services/price_storage_service.dart`
   وقم بتحديث `companyPhone` و `companyWhatsapp`.
